# 第二阶段2.1论文管理模块开发文档

## 开发时间
2024年（第3周）

## 开发目标
实现论文的完整CRUD功能，包括后端API和前端界面，支持分页、筛选、排序等高级查询功能。

## 完成情况

### ✅ 后端实现

#### 2.1.1 论文服务层 (`fastapi/services/paper_service.py`)

实现了完整的论文业务逻辑层，包含以下功能：

**核心功能：**
- ✅ `get_papers()` - 获取论文列表（支持分页、筛选、排序）
- ✅ `get_paper_by_id()` - 根据ID获取论文详情
- ✅ `create_paper()` - 创建新论文
- ✅ `update_paper()` - 更新论文信息
- ✅ `delete_paper()` - 删除论文

**筛选功能：**
- 按标题关键词模糊搜索
- 按作者关键词模糊搜索
- 按期刊/会议名称模糊搜索
- 按发表年份精确筛选
- 按分区（Q1/Q2/Q3/Q4）精确筛选

**排序功能：**
- 支持按任意字段排序（created_at, publish_year, impact_factor, title等）
- 支持升序/降序排序

**数据验证：**
- DOI唯一性检查（创建和更新时）
- 错误处理和异常抛出

#### 2.1.2 论文API路由 (`fastapi/api/papers.py`)

实现了完整的RESTful API接口：

**API端点：**
- ✅ `GET /api/papers` - 获取论文列表
  - 支持查询参数：page, page_size, title, authors, journal_conference, publish_year, partition, sort_by, sort_order
  - 返回分页结果，包含总数和总页数
- ✅ `GET /api/papers/{paper_id}` - 获取论文详情
- ✅ `POST /api/papers` - 创建论文
  - 需要认证（JWT token）
  - 请求体：PaperCreate schema
- ✅ `PUT /api/papers/{paper_id}` - 更新论文
  - 需要认证
  - 请求体：PaperUpdate schema（所有字段可选）
- ✅ `DELETE /api/papers/{paper_id}` - 删除论文
  - 需要认证
  - 返回204状态码

**认证保护：**
- 所有接口都需要JWT认证
- 使用 `get_current_user` 依赖注入进行认证检查

**错误处理：**
- 404错误：论文不存在
- 400错误：数据验证失败、DOI冲突等
- 500错误：服务器内部错误

#### 2.1.3 Schema更新 (`fastapi/schemas/paper.py`)

**新增Schema：**
- ✅ `PaperListResponse` - 论文列表响应模式
  - items: List[PaperResponse] - 论文列表
  - total: int - 总记录数
  - page: int - 当前页码
  - page_size: int - 每页数量
  - total_pages: int - 总页数

**现有Schema：**
- `PaperCreate` - 论文创建模式（所有字段可选，除title外）
- `PaperUpdate` - 论文更新模式（所有字段可选）
- `PaperResponse` - 论文响应模式（包含所有字段和时间戳）

   - 使用SQLAlchemy的链式查询
   - 根据筛选条件动态添加过滤条件
   - 使用 `contains()` 实现模糊搜索

3. **排序实现**

## API文档

### GET /api/papers

获取论文列表

**查询参数：**
- `page` (int, 可选): 页码，默认1
- `page_size` (int, 可选): 每页数量，默认10，最大100
- `title` (string, 可选): 标题关键词（模糊匹配）
- `authors` (string, 可选): 作者关键词（模糊匹配）
- `journal_conference` (string, 可选): 期刊/会议名称（模糊匹配）
- `publish_year` (int, 可选): 发表年份（精确匹配）
- `partition` (string, 可选): 分区，可选值：Q1, Q2, Q3, Q4
- `sort_by` (string, 可选): 排序字段，默认created_at
- `sort_order` (string, 可选): 排序方向，asc或desc，默认desc

**响应示例：**
```json
{
  "items": [
    {
      "id": 1,
      "title": "论文标题",
      "authors": "作者1, 作者2",
      "journal_conference": "期刊名称",
      "publish_year": 2024,
      "impact_factor": 3.5,
      "partition": "Q1",
      "doi": "10.1234/example",
      "abstract": "论文摘要",
      "keywords": "关键词1, 关键词2",
      "created_at": "2024-01-01T00:00:00",
      "updated_at": "2024-01-01T00:00:00"
    }
  ],
  "total": 100,
  "page": 1,
  "page_size": 10,
  "total_pages": 10
}
```

### POST /api/papers

创建论文

**请求体：**
```json
{
  "title": "论文标题",
  "authors": "作者1, 作者2",
  "journal_conference": "期刊名称",
  "publish_year": 2024,
  "impact_factor": 3.5,
  "partition": "Q1",
  "doi": "10.1234/example",
  "abstract": "论文摘要",
  "keywords": "关键词1, 关键词2"
}
```

**注意：** 只有 `title` 字段是必填的，其他字段都是可选的。

### PUT /api/papers/{paper_id}

更新论文

**路径参数：**
- `paper_id` (int): 论文ID

**请求体：**
```json
{
  "title": "更新后的标题",
  "impact_factor": 4.0
}
```

**注意：** 所有字段都是可选的，只更新提供的字段。

### DELETE /api/papers/{paper_id}

删除论文

**路径参数：**
- `paper_id` (int): 论文ID

**响应：** 204 No Content
