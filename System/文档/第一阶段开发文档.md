## 数据库表结构

### 用户表 (users)
- id: 主键
- username: 用户名（唯一）
- email: 邮箱（唯一）
- password_hash: 密码哈希
- role: 角色（admin/user）
- created_at: 创建时间
- updated_at: 更新时间

### 论文表 (papers)
- id: 主键
- title: 论文标题
- authors: 作者列表（JSON）
- journal_conference: 期刊/会议名称
- publish_year: 发表年份
- impact_factor: 影响因子
- partition: 分区
- doi: DOI
- abstract: 摘要
- keywords: 关键词
- created_at: 创建时间
- updated_at: 更新时间

### 专利表 (patents)
- id: 主键
- application_number: 申请号（唯一）
- authorization_number: 授权号（唯一）
- title: 专利名称
- inventors: 发明人列表（JSON）
- patent_type: 专利类型
- application_date: 申请日期
- authorization_date: 授权日期
- abstract: 摘要
- created_at: 创建时间
- updated_at: 更新时间

### 项目表 (projects)
- id: 主键
- project_number: 项目编号（唯一）
- project_type: 项目类型
- title: 项目名称
- principal_investigator: 负责人
- start_date: 开始日期
- end_date: 结束日期
- funding_amount: 资助金额
- task_description: 任务书内容
- status: 项目状态
- created_at: 创建时间
- updated_at: 更新时间

### 人员表 (personnel)
- id: 主键
- name: 姓名
- unit: 单位
- title: 职称
- research_direction: 研究方向
- email: 邮箱（唯一）
- phone: 电话
- created_at: 创建时间
- updated_at: 更新时间

### 关联表
- paper_project_relations: 论文-项目关联（含资助顺序）
- patent_project_relations: 专利-项目关联（含资助顺序）
- author_paper_relations: 作者-论文关联（含作者顺序）
- author_patent_relations: 发明人-专利关联（含发明人顺序）
- personnel_project_relations: 人员-项目关联（含角色）

## 使用说明

### 后端启动

1. 安装依赖：
```bash
cd fastapi
pip install -r requirements.txt
```

2. 配置环境变量：
```bash
cp .env.example .env
# 编辑 .env 文件，修改数据库连接等信息
```

3. 创建数据库：
```sql
CREATE DATABASE research_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

4. 初始化数据库：
```bash
python init_db.py
```

5. 启动服务：
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 前端启动

1. 安装依赖：
```bash
cd my-heroui-app
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

3. 访问应用：
- 前端：http://localhost:3000
- 后端API文档：http://localhost:8000/docs

## 遇到的问题及解决方案
