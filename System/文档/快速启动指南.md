# 快速启动指南

## 前置要求

- Python 3.8+
- Node.js 18+
- MySQL 5.7+ 或 8.0+

## 后端启动步骤

### 1. 进入后端目录
```bash
cd System/fastapi
```

### 2. 安装Python依赖
```bash
pip install -r requirements.txt
```

### 3. 配置环境变量
创建 `.env` 文件（参考 `.env.example`）：
```env
DATABASE_URL=mysql+pymysql://root:your_password@localhost:3306/research_management?charset=utf8mb4
SECRET_KEY=your-secret-key-here-change-in-production
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
DEBUG=True
PROJECT_NAME=科研成果管理系统
```

**注意：** 请将 `your_password` 替换为你的MySQL密码。

### 4. 创建数据库
在MySQL中执行：
```sql
CREATE DATABASE research_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 5. 初始化数据库表
```bash
python init_db.py
```

这将创建所有数据表，并创建默认管理员账户：
- 用户名：`admin`
- 密码：`admin123`

### 6. 启动后端服务
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

后端服务将在 http://localhost:8000 启动。

### 7. 验证后端服务
访问 http://localhost:8000/docs 查看API文档。

## 前端启动步骤

### 1. 进入前端目录
```bash
cd System/my-heroui-app
```

### 2. 安装依赖
```bash
npm install
```

### 3. 配置API地址（可选）
如果需要修改API地址，创建 `.env.local` 文件：
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

### 4. 启动开发服务器
```bash
npm run dev
```

前端应用将在 http://localhost:3000 启动。

### 5. 访问应用
打开浏览器访问 http://localhost:3000

## 测试登录

使用默认管理员账户登录：
- 用户名：`admin`
- 密码：`admin123`

登录成功后会自动跳转到仪表板页面。

## 常见问题

### 1. 数据库连接失败
- 检查MySQL服务是否启动
- 检查 `.env` 文件中的数据库连接信息是否正确
- 检查数据库用户是否有创建数据库的权限

### 2. 端口被占用
- 后端默认端口：8000
- 前端默认端口：3000
- 如果端口被占用，可以修改：
  - 后端：`uvicorn main:app --reload --port 8001`
  - 前端：修改 `package.json` 中的 `dev` 脚本

### 3. 依赖安装失败
- Python：确保使用正确的Python版本（3.8+）
- Node.js：确保使用正确的Node.js版本（18+）
- 如果遇到网络问题，可以使用国内镜像源

### 4. CORS错误
- 确保后端CORS配置中包含了前端地址
- 检查 `main.py` 中的 `allow_origins` 配置
