# 登录注册功能更新文档

## 更新日期
2024年（根据前端登录注册需求更新）

## 更新概述

根据前端登录注册页面的实际需求，对后端用户认证系统进行了调整，主要变更包括：
1. 添加手机号字段支持
2. 支持通过手机号登录
3. 更新注册流程以使用手机号
4. 前端注册页面字段调整

### 3. 后端服务层变更

#### 3.1 用户创建服务更新 (`fastapi/services/auth_service.py`)

**主要变更：**
1. 添加手机号唯一性检查
2. 邮箱检查改为可选（仅在提供邮箱时检查）
3. 创建用户时包含手机号字段

**关键代码：**
```python
def create_user(db: Session, user_create: UserCreate) -> User:
    """创建用户"""
    # 检查用户名是否已存在
    db_user = db.query(User).filter(User.username == user_create.username).first()
    if db_user:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="用户名已存在"
        )
    
    # 检查手机号是否已存在（新增）
    db_user = db.query(User).filter(User.phone == user_create.phone).first()
    if db_user:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="手机号已存在"
        )
    
    # 检查邮箱是否已存在（如果提供了邮箱）
    if user_create.email:
        db_user = db.query(User).filter(User.email == user_create.email).first()
        if db_user:
            raise HTTPException(
                status_code=status.HTTP_400_BAD_REQUEST,
                detail="邮箱已存在"
            )
    
    # 创建新用户
    hashed_password = get_password_hash(user_create.password)
    db_user = User(
        username=user_create.username,
        email=user_create.email,
        phone=user_create.phone,  # 新增
        password_hash=hashed_password,
        role=user_create.role
    )
    db.add(db_user)
    db.commit()
    db.refresh(db_user)
    return db_user
```

#### 3.2 用户认证服务更新

**主要变更：**
支持通过用户名或手机号登录

**关键代码：**
```python
def authenticate_user(db: Session, username: str, password: str) -> User:
    """验证用户 - 支持通过用户名或手机号登录"""
    # 先尝试通过用户名查找
    user = db.query(User).filter(User.username == username).first()
    # 如果用户名不存在，尝试通过手机号查找
    if not user:
        user = db.query(User).filter(User.phone == username).first()
    
    if not user:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="用户名/手机号或密码错误",
            headers={"WWW-Authenticate": "Bearer"},
        )
    
    if not verify_password(password, user.password_hash):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="用户名/手机号或密码错误",
            headers={"WWW-Authenticate": "Bearer"},
        )
    
    return user
```

```typescript
  }
```

## 数据库迁移说明

### 重要提示

⚠️ **如果数据库中已有数据，需要进行数据库迁移：**

1. **添加phone字段：**
   ```sql
   ALTER TABLE users 
   ADD COLUMN phone VARCHAR(20) NULL AFTER email;
   ```

2. **为现有用户设置手机号（临时方案）：**
   ```sql
   UPDATE users 
   SET phone = CONCAT('1380000', id) 
   WHERE phone IS NULL;
   ```

3. **设置phone字段为唯一索引：**
   ```sql
   CREATE UNIQUE INDEX idx_phone ON users(phone);
   ```

4. **设置phone字段为必填：**
   ```sql
   ALTER TABLE users 
   MODIFY COLUMN phone VARCHAR(20) NOT NULL;
   ```

5. **将email字段改为可选：**
   ```sql
   ALTER TABLE users 
   MODIFY COLUMN email VARCHAR(100) NULL;
   ```

### 推荐方案：重新初始化数据库

如果项目处于开发阶段，建议删除现有数据库并重新初始化：


## API接口变更

### 注册接口 (`POST /api/auth/register`)

**请求体变更：**
```json
{
  "username": "张三",      // 必填：用户姓名
  "phone": "13800138000", // 必填：手机号（新增）
  "email": "user@example.com", // 可选：邮箱
  "password": "password123"    // 必填：密码
}
```

**响应体变更：**
```json
{
  "id": 1,
  "username": "张三",
  "email": "user@example.com",  // 可选，可能为null
  "phone": "13800138000",       // 新增
  "role": "user",
  "created_at": "2024-01-01T00:00:00"
}
```

### 登录接口 (`POST /api/auth/login`)

**功能增强：**
- 现在支持通过用户名或手机号登录
- `username` 字段可以传入用户名或手机号
- 后端会自动识别并查找对应的用户

**请求体（不变）：**
```
username=13800138000 或 username=admin
password=password123
```

**响应体变更：**
```json
{
  "access_token": "eyJ...",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "username": "张三",
    "email": "user@example.com",  // 可选
    "phone": "13800138000",       // 新增
    "role": "user",
    "created_at": "2024-01-01T00:00:00"
  }
}
```

### 获取当前用户接口 (`GET /api/auth/me`)

**响应体变更：**
现在包含 `phone` 字段，`email` 字段可能为 `null`。
